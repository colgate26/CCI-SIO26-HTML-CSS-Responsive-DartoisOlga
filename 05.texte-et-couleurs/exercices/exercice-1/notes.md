# Exercice 1

`html { font-size: 18px; }` : pour mettre la taille de base, en premier car c'est a partir de ca que les tailles sont calculées

`body { font-family: "Segoe UI", Arial, Helvetica, sans-serif; color: #222222; background-color: #f5f5f5; }` : police sans empattement, couleur lisible gris tres foncé et fond gris clair

`h1 { text-align: center; color: #0b3d91; }` : titre centré en bleu foncé en hexadecimal

`h2 { color: rgb(11 61 145); font-size: 1.5rem; font-weight: bold; }` : meme bleu foncé en rgb 1.5 fois la taille de base en gras

`.sous-titre { font-style: italic; color: #555555; text-align: center; }` : les sous titreen italic, gris et centré

`.chapo { font-weight: bold; font-size: 1.1rem; }` : en gras et 1.1 fois la taille de base

`.note { background-color: hsl(60, 100%, 90%); color: #5c3317; }` : fond jaune pale et ecriture brun foncé, contraste ok

`footer { text-align: center; font-size: 0.85rem; }` : pied de page centré 0.85 fois la taille de base
